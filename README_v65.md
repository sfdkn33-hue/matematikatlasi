# Matematik Atlası v6.5 — kazanım kalite haritası

## Kullanım

1. `index.html` ya da `ATLAS_TEK_DOSYA.html` dosyasını aç.
2. Ana ekrandaki **Kazanım kalite haritası** düğmesini kullan. Sınıf/öncelik/arama filtresi yap; kartı açınca alt beceri taslağı, metin aileleri, gerçek örnek görevler görünecek.
3. Bağımsız inceleme için `KAZANIM_KALITE_HARITASI.html` aç. İnceleme için `data/atlas65_audit.csv` veya Excel dosyasını kullan.
4. 8. sınıfta Doğrusal Denklemler > Bir bilinmeyenli denklem / Koordinat Sistemi kazanımlarının son 8'er görevini açarak yeni soruları oyna.

**Uyarı:** 130 kodun tamamına görev bağlanması tam öğrenme kanıtı değildir. Otomatik tahmin edilen soru aileleri ve alt beceri taslakları pedagojik inceleme bekliyor. 76 pilot görevde ilk deneme / ipucu takibi yapılabilir. Öğretmen onayı yok. Canlı GitHub'a dokunulmadı.
