- `ATLAS_TEK_DOSYA.html`: İnternete gerek olmadan açılabilir tek dosya; yerel tarayıcı dosya depolaması tarayıcıya bağlıdır.
- `index.html`: Tüm alt klasörlerle birlikte çalışır.
